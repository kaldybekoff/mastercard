# MDQ 2026 — Инструкции для Claude Code

Ты работаешь над хакатон-проектом MDQ (Mastercard Data Quest 2026 — поиск скрытых предпринимателей среди физлиц).

Весь контекст проекта находится в папке docs/:

- docs/HANDOFF.md — **читай первым в каждом новом чате**. Текущий статус проекта, что уже сделано, ключевые находки EDA, ТЗ на следующий шаг. Обновляй в конце каждой сессии.
- docs/CASE.md — описание кейса и данных (включает раздел "Факты о данных из EDA" с реальными числами)
- docs/SOLUTION.md — архитектура ML-решения (PU-bagging, LightGBM, сегментация)
- docs/FEATURES.md — все ~80 фичей с бизнес-обоснованием (обновлён по результатам EDA)
- docs/STACK.md — технический стек
- docs/CRITERIA.md — критерии оценки жюри
- docs/GIT_WORKFLOW.md — правила работы с git

## Правила

1. Перед написанием любого кода — прочитай релевантные файлы из docs/
2. Если в процессе работы появилась новая идея фичи, изменился подход или найдено ограничение — сразу обнови соответствующий .md файл
3. src/config.py — единственный источник констант (пути, MCC-коды, пороги, ROI). Никаких хардкодов в ноутбуках и src-файлах
4. Весь переиспользуемый код — в src/. Ноутбуки только импортируют из src/ и вызывают функции
5. random_state=42 везде где есть случайность

## Правило по HANDOFF.md

- В начале новой сессии — прочитай `docs/HANDOFF.md` чтобы понять где проект сейчас
- В конце сессии (когда шаг завершён) — обнови `docs/HANDOFF.md`: замени "Следующий шаг" на новый, добавь ключевые находки текущей сессии
- HANDOFF.md — живой документ, он всегда отражает актуальное состояние проекта

## Рабочий процесс с данными

- Пользователь запускает ноутбуки сам — Claude не выполняет `jupyter nbconvert --execute`
- Если ноутбук упал — пользователь присылает traceback, Claude фиксит код
- Если получены новые числа/графики — Claude сразу обновляет соответствующий .md файл

## Окружение

- Python `.venv` в корне репо: `.venv\Scripts\python.exe`
- Зависимости установлены без version pins (Python 3.13 несовместим с numpy<2.0.0 из requirements.txt)
- Jupyter kernel: "Python (mdq .venv)"
